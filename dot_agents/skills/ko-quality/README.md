# ko-quality — 에이전트가 쓰는 한국어를 사람이 읽을 만하게

> LLM 에이전트용 스킬입니다. 에이전트가 Slack 공지, 문서, PR 설명 같은
> **남에게 읽힐 한국어**를 만들 때 자동으로 끼어들어 품질을 관리합니다.

## 왜 필요한가

에이전트가 쓴 한국어를 읽다 보면 이런 문장을 만납니다.

- "쓰기는 **비차단**으로 처리됩니다." — 사전에 없는 합성어. 무슨 뜻인지
  검색해도 안 나옵니다.
- "**승격 로직**은 결국 **2안**으로 확정했습니다." — 그 대화에 없던 사람은
  '2안'이 뭔지 알 수 없습니다. 에이전트 자신만 아는 단어입니다.
- "이 기능은 다양한 편의성을 제공함으로써, 전반적인 경험을 향상시키는 것을
  목표로 하고 있습니다." — 문법은 맞는데 아무 정보가 없는, 전형적인 AI
  문장입니다.

문법 검사기는 이런 문장을 잡지 못합니다. 문제는 맞춤법이 아니라 **단어 선택과
문장 구사**이기 때문입니다. ko-quality는 바로 그 영역을 관리합니다.

## 무엇을 하는가

한 문장으로 줄이면 이렇습니다. **읽는 사람의 사전에 있는 단어로, 사람이 쓴 것
같은 한국어를 쓰게 만듭니다.**

- **원칙 29개를 생성 시점부터 적용합니다.** 번역투("~에 대해", "~을 통해",
  "~되어지다"), AI 상투어("혁신적", "다양한", "전반적인"), 영어식 쉼표 남발,
  세션 안에서만 통하는 어휘 등을 처음부터 피해서 씁니다. 원칙마다 나쁜
  예와 고친 예가 붙어 있습니다.
- **무거운 산출물은 검수를 한 번 더 돌립니다.** 문서·공지·보고서급은 초안을
  쓴 뒤 별도 검수 에이전트가 원칙 위반을 찾아 교정하고 심각한 위반이
  있었다면 재검수까지 합니다. 한 번에 다 지키기는 어렵다는 걸 전제로 만든
  구조입니다.
- **여러분의 말투를 존중합니다.** 채널의 기존 톤과 저장소의 커밋 이력, 이웃
  문서의 관례까지 관찰해서 따라갑니다. 스킬이 강요하는 표준 문체는 없고
  영어로 쓰던 걸 한국어로 바꾸지도 않습니다.

## 언제 발동하는가

| 자동 발동 | 발동 안 함 |
|---|---|
| Slack 메시지·공지 | 세션 안의 일상 대화 |
| 저장소 문서, Confluence/Jira | 임시 메모·스크래치 파일 |
| PR 설명·리뷰 코멘트 | 영어 출력 전부 |
| 한국어 커밋 메시지, 한국어 코드 주석 | |
| "이거 공유할 거야"라고 말한 출력 | |

직접 실행하려면 `/ko-quality`를 입력하면 됩니다.

## 원칙은 어디서 왔고 어떻게 자라는가

- 코어는 공개 스킬셋 [daleseo/korean-skills](https://github.com/daleseo/korean-skills)의
  스킬 3개(humanizer, style-guide, grammar-checker)에서 핵심만 추려 왔습니다.
  humanizer는 한국어 AI 문체 연구(KatFishNet)가 찾아낸 패턴 40개를 담고
  있는데 그중 정보 전달을 실제로 해치는 것부터 골랐습니다.
- 여기에 실사용에서 발견한 자체 원칙을 계속 추가합니다. 예를 들어 "세션
  어휘 금지", "사전에 없는 압축 합성어 금지"는 에이전트와 일하며 귀납적으로
  얻은 원칙입니다. 에이전트에게 "이 패턴 원칙으로 추가해"라고 말하면
  됩니다. 등재 절차는 스킬이 스스로 압니다.

## 써보려면

1. `npx skills add daleseo/korean-skills`로 코어 스킬 3개를 설치합니다.
2. `ko-quality` 디렉터리(이 폴더)를 `~/.agents/skills/`에 복사합니다. Claude
   Code를 쓴다면 `~/.claude/skills/`에 심링크를 겁니다.
3. 에이전트 전역 지침(CLAUDE.md 등)에 "남에게 공유되거나 저장소에 남을
   한국어 출력 전에 ko-quality 발동" 한 줄을 넣으면 발동 신뢰도가 올라갑니다.

원칙 전문은 [`references/principles.md`](references/principles.md)에
있습니다. 각 원칙에 출처가 달려 있어 어디서 온 규칙인지 추적할 수 있습니다.
