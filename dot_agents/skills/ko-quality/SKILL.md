# ko-quality: 한국어 출력 품질 관리

에이전트가 만드는 한국어 출력 중 **다른 사람에게 공유되거나 영속되어 읽힐 것**의
품질을 관리한다. 원칙 정본은 이 스킬이 소유하고, 심층 검수는 korean-skills 3종
(humanizer, style-guide, grammar-checker)에 위임한다.

## 불변 원칙

- **언어를 선택하지 않는다.** 이미 한국어로 쓰(려)는 출력의 품질만 관리한다.
  영어로 쓰던 출력을 이 스킬 때문에 한국어로 바꾸지 않는다.
- **컨벤션은 원칙의 하위다.** 워크스페이스에서 관찰한 이력에서는 정당한 선택지
  중의 선택(어조, 종결형, 구조 관례)만 상속한다. principles.md가 결함으로
  규정하는 패턴은 이력에 아무리 많아도 컨벤션으로 승격하지 않는다. 에이전트
  저작 흔적(`Co-Authored-By:` 트레일러, 봇 계정)이 있는 표본은 가중치를 낮추고
  사용자 본인 저작 표본을 우선한다.
- **의미 보존이 교정에 우선한다.** 의미가 바뀔 소지가 있는 교정은 적용하지
  않고 사용자에게 플래그한다.

## 절차

1. `references/principles.md`를 읽는다 — 원칙 목록, 컨벤션 발견 절차, 폴백이
   모두 거기 있다.
2. 아티팩트 클래스를 판정하고, principles.md의 컨벤션 발견 절차대로 해당
   워크스페이스의 컨벤션(어조·종결형·구조)을 파악한다.
3. 모드를 판정한다.
   - **경량**: 커밋 메시지, 짧은 Slack 메시지, 코드 주석 등 몇 문장 수준.
   - **중량**: 문서, 공지, 보고서, Confluence/Jira 본문, 게시형 산출물(예: Claude Code의 Artifact), 공유
     승격된 채팅 보고서 등 문단 이상.
4. 원칙과 발견한 컨벤션을 따라 작성한다. **경량 모드는 여기서 끝.**
5. 중량 모드는 아래 검수 프로토콜을 실행한다.

## 검수 프로토콜 (중량 모드)

1. 초안을 파일로 둔다 (이미 파일이면 그대로).
2. **검수 서브에이전트 1기**를 스폰한다 (메인 컨텍스트를 오염시키지 않기 위한
   격리 — 3종 스킬 본문과 references가 수십 KB다). 프롬프트 골격:

   > 너는 한국어 검수자다. `<초안 파일>`을 읽고 humanizer, style-guide,
   > grammar-checker 스킬을 차례로 발동해 검수하라.
   > `~/.agents/skills/ko-quality/references/principles.md`의 원칙 위반도
   > 검사하라. 기대 컨벤션: `<발견한 컨벤션>`. 파일을 수정하지 말고 발견
   > 사항만 반환하라. 각 항목: 위치, 원문, 문제(원칙 ID 또는 패턴명),
   > 심각도(S1/S2/S3), 제안 교정.

   초안이 수 KB 이상이면 체커별 병렬 3기(humanizer / style-guide /
   grammar-checker+자체 원칙)로 분할한다.
   이 서브에이전트의 **모델·effort는 작업에 맞춰 고른다 — 세션 tier를 반사적으로
   상속하지 마라.** 검수는 정해진 원칙 목록을 적용하는 경계 뚜렷한 작업이라 대개
   중간 등급 모델·낮은 effort로 족하고, 초안이 길거나 언어 판정이 미묘할 때만
   올린다. 특정 모델명에 고정하지 말고(모델은 바뀐다) 이 기준으로 그때의 가용
   모델에서 고른다. 모델과 effort를 둘 다 per-call로 지정하려면 두 노브를 여는
   실행 수단(예: Claude Code 세션이라면 Workflow의 `agent` 호출)을 쓴다 — 모델만 내리고 effort는
   세션값을 상속하면 절반만 최적화된다.
3. 발견 사항을 메인이 직접 교정 적용한다 (단일 작성자 유지). 의미 변경 소지가
   있는 항목은 적용하지 않고 플래그로 모은다.
4. **종료 조건**: S1이 하나라도 있었으면 교정 후 재검수 1회 (교정 자체가 새
   결함을 만들 수 있다). S1 = 0이면 종료. 최대 2라운드 — 수렴하지 않으면 잔여
   사항을 보고하고 종료한다.
5. 사용자에게 2~3줄로 검수 요약을 남긴다: 찾은 것, 고친 것, 안 고친 것과 이유.

## 캡처 — 자체 원칙 추가

사용자가 새 원칙을 지시하면 ("이 패턴 원칙으로 추가해"):

1. principles.md에서 겹치는 원칙을 먼저 찾는다. 겹치면 기존 원칙을 병합·강화
   한다 — 경쟁하는 중복 항목을 만들지 않는다.
2. 신규면 다음 KO-번호로 추가한다: 심각도, 출처 `자체발견 YYYY-MM-DD`,
   ❌/✅ 예시 1쌍 포함.
3. 정본은 chezmoi 소스다. `chezmoi source-path ~/.agents/skills/ko-quality/references/principles.md`
   로 소스 파일을 찾아 수정하고, `chezmoi apply` 후 커밋한다.
4. 파일이 ~15KB를 넘으면 우선순위 최하위 원칙의 정리를 사용자에게 제안한다.

## 업스트림 재증류

principles.md 헤더의 증류 스탬프(korean-skills 커밋/해시)와
`~/.agents/.skill-lock.json`의 `skillFolderHash`가 다르면 업스트림이 갱신된
것이다. 바뀐 references를 diff해 원칙 목록에 반영하고 스탬프를 갱신한다.
