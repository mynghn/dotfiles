# 독자를 코드로 데려가는 여섯 가지 꼴

[고르기](#고르기)

독자의 목적이 필요로 하는 것으로 고른다. 다이제스트 하나에 보통 두세 개가 들어
간다. 여섯 개를 다 쓴 다이제스트는 선별을 그만둔 것이다. 각 꼴마다 무엇에 쓰이고,
어떤 모양이고, 어떻게 실패하는지를 적었다.

## 1. 읽기 경로

**쓰임** — 코드를 직접 열어볼 독자에게 문 하나와 순서를 준다.

열어볼 자리를 순서대로 나열하고, 각각에 거기서 볼 것 한 가지와 그것이 왜 이
자리에 오는지를 붙인다. 시작은 실제 진입점이어야 한다 — `main`, 라우트 등록,
핸들러, CLI 명령, 전체를 돌리는 테스트. 알파벳순으로 첫 번째인 파일이 아니다.

```
1. cmd/serve.go:31 — 프로세스가 여기서 시작한다. 렌더러가 모델보다 먼저 정해지는 걸 눈여겨볼 것.
2. renderer/cursed.go:88 — 고른 렌더러의 계약. 아래 모든 것이 이걸 전제한다.
3. …
```

**실패하는 지점** — 줄 번호가 붙은 파일 목록이 될 때. "왜 이 자리인가" 칸이
비어 있으면 경로가 아니라 디렉터리다.

## 2. 대표 시나리오 엔드투엔드 트레이스

**쓰임** — 거의 모든 독자에게. 정적 구조와 런타임 행동을 잇는 다리이고,
다이제스트에서 가장 확실하게 값을 하는 조각이다.

구체적이고 대표성 있는 사례 하나를 고른다 — 실제 값이 든 요청, 파이프라인을
지나는 레코드, 핸들러에 닿는 키 입력. 그것을 입구에서 출구까지 따라가며 지나는
자리마다 이름을 대고 거기서 무슨 일이 일어나는지 말한다. 시퀀스 그림을 짝지어
독자가 자기가 읽는 모양을 눈으로 보게 한다.

시나리오는 작업의 핵심을 지나는 것으로 고른다. 심심한 경로를 따라간 트레이스는
아무것도 가르치지 않는다.

**실패하는 지점** — 값이 추상으로 남을 때. "요청이 검증된다"는 산문이고, "만료된
토큰을 단 `POST /orders`가 `auth/middleware.py:44`에 닿고, 거기서 핸들러가 돌기
전에 401이 나간다"가 트레이스다.

## 3. 핵심 메커니즘 해부

**쓰임** — 무게가 알고리즘·불변식·상태 기계·프로토콜 하나에 실린 작업.

하중을 지는 그 하나를 끝까지 연다. 무엇을 보장하는지, 어떻게 보장하는지, 어떤
불변식이 유지돼야 하는지, 유지되지 않으면 무슨 일이 나는지. 충실성 계약이 가장
세게 걸리는 자리다 — 어려운 부분이 바로 독자가 찾아온 이유이므로, 여기만은
압축하면 안 된다.

메커니즘이 동시성이나 순서 보장이면 **무엇이 무엇에 의해 어느 경계를 가로질러
보호되는지**를 있는 그대로 말한다. 독자가 가장 자주 틀리는 주장이 그것이다.

**실패하는 지점** — 보여주지 않고 단언할 때. 그림도 트레이스도 인용도 없는
메커니즘 절은 제목을 뒤집어쓴 주장일 뿐이다.

## 4. 결정 지점 지도

**쓰임** — 이 작업이 다른 길로 갈 수도 있었던 자리를 알아야 하는 독자.

진짜 대안이 있었던 곳들: 무엇을 골랐고, 무엇 대신 골랐고, 무엇을 내줬는지.
기록이 이걸 대놓고 말해줄 때가 많다 — "참조를 복제하는 대신 핸들러만 캡처하기로
했다"는 문장은 결정 지점을 통째로 건네주는 것이다.

결정과 그 대가를 보고하고, 평가는 독자가 한다. 근거의 출처를 표시하라: 설명에서
온 근거는 `stated`, 코드에서 되짚어낸 근거는 `inferred`.

**실패하는 지점** — 차이란 차이를 전부 "결정"으로 만들 때. 결정 지점에는 살아
있던 대안이 필요하다. 합리적인 길이 하나뿐이었다면 그건 선택이 아니라 메커니즘
이다.

## 5. 로컬 이디엄 사전

**쓰임** — 온보딩과 인수인계. 독자가 다이제스트를 덮은 뒤에도 계속 읽어야 하는
상황.

이 코드베이스에서 되풀이되는 패턴, 이름 짓는 관례, 자체 헬퍼들 — 한 번 알고 나면
전에는 해독해야 했던 코드가 훑어진다. 서너 개에서 일곱 개, 각각에 실제 자리를
가리키는 예 하나씩.

```
`*Msg` 타입 — 런타임이 전달하는 모든 이벤트는 값이다. 콜백이 아니다. tea.go:210.
`fooOrDie(…)` — 셋업 오류에서 패닉하는 자체 헬퍼. 초기화 중에만 정당하다.
```

**실패하는 지점** — 로컬 관례가 아니라 언어 기능을 늘어놓을 때. 독자는 데코레이터가
뭔지 안다. 모르는 것은 이 코드베이스에서 데코레이터가 "임포트 시점에 등록됨"을
뜻한다는 사실이다.

## 6. 취약한 전제와 불변식

**쓰임** — 읽기만 하는 것이 아니라 고칠 사람.

무엇이 계속 참이어야 하는지, 무엇이 실수로 깨지기 쉬운지, 무엇이 멀리 떨어진
무엇과 묶여 있는지. 서술만 한다 — 전제와 그것이 기대어 있는 자리를 대서 독자가
머릿속에 얹고 다니게 한다.

```
`lastView`는 뮤텍스 아래에서 쓰이고 마우스 경로에서 읽힌다. 이 필드를 새로 읽는
코드는 전부 같은 락을 잡아야 한다 (renderer/cursed.go:88, renderer/cursed.go:141).
```

**실패하는 지점** — 코드 채점으로 흘러갈 때. 제약과 그것이 걸리는 자리를 대고,
어떻게 볼지는 독자가 정한다.

## 고르기

오리엔테이션과 인수인계는 1·2·5·6에 기댄다. 특정 변경을 이해하는 일은 2·3·4에
기댄다. 낯선 프로젝트를 가늠하는 일은 2·4에 기대고, 3은 그 프로젝트가 흥미롭다고
주장하는 지점에만 쓴다.

예산이 짧으면 **트레이스(2)가 남고 나머지가 양보한다.** 여기 있는 무엇보다 줄당
이해를 많이 실어 나른다.
